# SecureAuth – Mini Security Project

SecureAuth is a mini project based on a microservices architecture.
It focuses on secure authentication, access control, and security audit logging.

## Microservices
- Auth Service: user registration and authentication (JWT)
- Profile Service: protected user profile access
- Audit Service: security event logging

## Technologies
- Node.js / Express
- Docker & Kubernetes
- CI/CD with Jenkins
- Monitoring with Prometheus & Grafana
